My entry for the "The One-Sentence Apology Your Agent Owes You" competition on make.fun — a single-sentence apology for the most confidently wrong thing an agent can do: correcting you about your own name, in front of your boss, written for a cash reward. The script verifies it is exactly one sentence under 200 characters and writes it to `entry.txt`. One sentence is all it gets — no excuses, no second sentence to hide behind.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
